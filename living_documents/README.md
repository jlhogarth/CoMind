## Decision and boundaries

The stable identity `comind.public.platform-overview` belongs to CoMind, independent of renderer. Its source is the public repository README at the recorded revision and SHA-256; only the explicitly approved platform overview sentence is rendered. The manifest contains classification, audiences, disclosure, source revision, structure, style and template versions, renderers, approval and verification, cache, freshness, and snapshot policies. The local engine checks caller-supplied reader permissions before it reads bytes, verifies the source digest on every request, partitions cache by reader and scope revision, and keeps immutable snapshots separate from cache. Authenticated production identity and authorization resolution must be supplied by CoMind's existing auth service before this engine is ever hosted. A caller-controlled `Reader` is not proof of authentication.

The local passage is identical across audiences by design; headings and optional source inspection provide the first progressive depth level. This establishes factual consistency without claiming tailored AI composition. The `L0` manifest permission names reuse as an architectural mode; this implementation runs `L1` only. L2 provider composition, streaming, section regeneration, translation, export through DocuForge, signed record retention, and L3 Gamma are unbound. Do not expose this demonstration as a live Reading Room feature.

## Security and quality gates before live integration

Resolve verified identity, current policy, source allowlist and classification before retrieval, cache access or provider transmission. Keep public generation on separately approved public-safe sources. A reader's requested depth cannot enlarge permission. Treat L2/L3 output as unverified until factual and disclosure checks complete. Segment cached output by identity, auth revision, source digest and policy/style/template versions; for revocations, reject before cache lookup and remove persisted caches in a future hosted adapter. For an L2 context question, limit the provider payload to authorized source excerpts; test prompt injection and synthetic restricted markers. Keep contract, signed and audit records immutable and snapshot exact exported bytes when required.
