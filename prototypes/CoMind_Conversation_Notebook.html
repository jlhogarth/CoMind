source_records Source text, origin, hash, project identity

Scope boundary

CoMind project identity uses the canonical project UUID. Personal continuity is separate and local in this prototype. The active CoMind database is not the Test database.

Test fixture only. Never apply it to production. It creates no second memory table, runtime service, grant, or production identity contract.
